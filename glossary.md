# Tiny glossary

Plain-English meanings for words you'll bump into. You don't need to memorise
any of this — it's just here when a word looks unfamiliar. (You can also ask
Claude "what does ___ mean?" any time.)

| Word | What it means |
| --- | --- |
| **File** | A single document on your computer — like `index.html`. |
| **Folder** | A container that holds files (and other folders). Your whole website lives in one folder. |
| **File path** | The "address" of a file, e.g. `assets/photo.jpg` means "the photo.jpg inside the assets folder". |
| **HTML** | The **content and structure** of a web page — the words, headings, images, and how they're ordered. Files ending in `.html`. |
| **CSS** | The **look** — colours, fonts, spacing, layout. This site's CSS lives in `styles.css`. |
| **JavaScript** | Adds **behaviour** — things that happen, like the menu opening on a phone. This site's is in `script.js`. |
| **Browser** | The app you view websites in — Chrome, Safari, Firefox, Edge. |
| **Refresh** | Reloading the page in the browser (Cmd+R) so you see your latest changes. |
| **Tag** | A building block of HTML, written in angle brackets, e.g. `<h1>` for a big heading or `<img>` for an image. |
| **Element** | One thing on the page made from tags — a heading, a paragraph, an image, a button. |
| **Class** | A label on an element (like `class="card"`) that CSS uses to style it. |
| **Design token** | A saved setting for a colour, font, or spacing value, kept at the top of `styles.css`. Change it once and it updates everywhere. |
| **Alt text** | A short written description of an image, for people who can't see it (and for screen readers). You'll be asked to write these. |
| **Responsive** | A site that rearranges itself to look good on any screen size — phone, tablet, or laptop. |
| **Accessibility** | Making sure everyone can use your site, including people who use a keyboard instead of a mouse, or a screen reader. |
| **Zip** | A single compressed file that bundles your whole folder together — what you upload to hand in. |
